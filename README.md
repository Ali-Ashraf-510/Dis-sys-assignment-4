# Chat Room

Simple chat app in Go.

## How to Use

1. **Start Server:**
   ```
   go run server.go
   ```

2. **Start Client:**
   ```
   go run client.go
   ```

3. **Chat:**
   - Enter your name
   - Type messages
   - Type `exit` to quit

## Files
- `server.go` - Server
- `client.go` - Client
